# TIVA simulator A teaching simulator for total intravenous anaesthesia: a patient monitor, TCI pumps and an instructor remote that share one simulated patient. **For education only. Not for clinical use.** The drug kinetics use published pump models, but the patient's response to the drugs is a simplified teaching model. ## Starting it You need [Node.js](https://nodejs.org) 20 or later. Nothing else has to be installed, and no internet is needed. ```bashnpm start``` Then open `http://localhost:8080` on the same computer. The terminal also prints the address for other devices, for example `http://192.168.1.20:8080`. ## Setting up a workshop 1. Connect the laptop that runs the simulator to the venue Wi-Fi, or to a phone hotspot if there is no Wi-Fi. Internet access is not needed, only a shared network.2. Run `npm start` and leave the terminal open. Keep the laptop plugged in and stop it from sleeping.3. Connect each tablet, laptop or phone to the same network and open the address printed in the terminal. The instructor page also shows this address.4. On each device, type the **station code** and choose a screen:   - **Patient monitor** for the screen trainees watch.   - **TCI pumps** for the device trainees operate.   - **Instructor remote** for your own phone or laptop. Screens with the same station code share one patient. Use a different code for each station (for example 1, 2, 3 and 4). Up to 12 stations can run at once. If a device cannot connect, check that it is on the same network as the laptop and that the laptop's firewall allows incoming connections for Node.js. Some guest and hospital Wi-Fi networks block devices from reaching each other; a phone hotspot avoids this. ## Running a case - Choose the patient type on the instructor remote and press **Start new case**. Tell the trainees the patient's age, weight, height and sex so they can program the pumps.- Trainees program and start the pumps. The patient's Entropy, blood pressure, heart rate, breathing and saturation respond to the drugs delivered.- When the patient stops breathing, saturation falls after the preoxygenation time unless you select **Ventilated**.- Use the event buttons for intubation, incision, ongoing stimulation, bleeding, a disconnected IV line or an occluded pump.- Set any vital sign yourself at any time. **Auto** hands it back to the model.- Use the speed buttons to run faster than real time, and **Pause** to stop and discuss.- Tick **Lock the monitor** to stop trainees changing values on the monitor screen.- Download the case log from the instructor remote for the debrief. Each screen has a **Sound** button. Browsers only allow sound after a button has been pressed, so turn it on at each device. ## What is in the simulator | Part | Details ||---|---|| Pump models | Propofol: Marsh, Marsh with fast ke0, Schnider, Eleveld, Paedfusor, Kataria. Remifentanil: Minto, Eleveld. Sufentanil: Gepts. Dexmedetomidine: Hannivoort. Ketamine: Domino. || Pump styles | Generic, Alaris PK style, Agilia style, Space style. The brand-style step orders are approximations and should be checked against the real pumps. || Monitor | ECG, SpO2, EtCO2, invasive arterial pressure, CVP, respiration, Entropy, temperature, NIBP and NMT, each of which can be added or removed. || Patients | Fit adult, frail elderly, obese adult, child, anxious young adult. | ## Known limits - These constants could not be confirmed against a source and should be checked against a pump manual: the Kataria parameter set, the Paedfusor values for ages 13 to 16, and the sufentanil ke0.- How far blood pressure, heart rate and breathing move with the drugs is a teaching approximation. The values are in `src/sim/patient.js`.- The heart rhythm is sinus only, plus asystole at a heart rate of 0.- Restarting the server clears every station. ## For developers ```bashnpm test``` - `src/engine` holds the pharmacokinetic models and the TCI controller.- `src/sim` holds the pump logic, the patient model and the station that ties them together.- `public` holds the three screens.- `server.js` serves the pages and runs the stations. Screens receive state over server-sent events and send actions with `POST /api/action`. The full specification and developer documents are in [`docs/`](docs/README.md).

// One syringe pump channel: the pump's own prediction of the patient plus the// controller that decides the infusion rate.// FOR EDUCATION ONLY. NOT FOR CLINICAL USE.//// The concentrations here are what the PUMP believes (its display values). The// simulated patient is a separate model fed with `deliveredRate`, so that a// disconnected line or a sensitive patient can differ from the pump's display. import { buildStepper, advance, emptyState } from './pk.js'; const CONTROL_INTERVAL_S = 10; // the controller recalculates the rate this oftenconst EFFECT_HORIZON_STEPS = 360; // look-ahead for effect-site targeting (1 hour) export const MODES = { OFF: 'off', PLASMA: 'plasma', EFFECT: 'effect', MANUAL: 'manual' }; export class Infusion {  /**   * @param {object} opts   * @param {object} opts.model          from buildModel()   * @param {number} opts.concentration  syringe concentration, dose units per mL   * @param {number} [opts.maxRateMlH]   fastest the pump can run (default 1200 mL/h)   */  constructor({ model, concentration, maxRateMlH = 1200 }) {    if (!(concentration > 0)) throw new Error('concentration must be positive');    this.model = model;    this.concentration = concentration;    this.maxRateMlH = maxRateMlH;    this.second = buildStepper(model, 1);    this.interval = buildStepper(model, CONTROL_INTERVAL_S);     // Effect-site response to one control interval at unit rate, then nothing.    this.unitEffect = [];    let s = advance(this.interval, emptyState(), 1);    for (let k = 1; k <= EFFECT_HORIZON_STEPS; k++) {      this.unitEffect.push(s[3]);      s = advance(this.interval, s, 0);    }     this.state = emptyState();    this.timeS = 0;    this.mode = MODES.OFF;    this.target = 0;    this.manualRate = 0; // dose units per minute    this.bolusRemaining = 0; // dose units    this.paused = false;    this.controlRate = 0;    this.deliveredRate = 0; // dose units per minute during the last second    this.totalDose = 0;    this.untilControl = 0;  }   get maxRate() {    return (this.maxRateMlH / 60) * this.concentration; // dose units per minute  }  get cp() {    return this.state[0] / this.model.v1;  }  get ce() {    return this.model.ke0 == null ? null : this.state[3];  }  get rateMlH() {    return (this.deliveredRate / this.concentration) * 60;  }  get volumeMl() {    return this.totalDose / this.concentration;  }   /** Start or change a target-controlled infusion. mode is 'plasma' or 'effect'. */  setTarget(mode, target) {    if (mode !== MODES.PLASMA && mode !== MODES.EFFECT) throw new Error(`Unknown TCI mode: ${mode}`);    if (mode === MODES.EFFECT && !this.model.effectSiteTargeting) {      throw new Error(`${this.model.name} does not support effect-site targeting`);    }    if (!(target >= 0)) throw new Error('target must be zero or more');    this.mode = mode;    this.target = target;    this.bolusRemaining = 0;    this.untilControl = 0; // recalculate immediately  }   /** Run at a fixed rate in mL/h (manual mode). */  setManualRateMlH(mlH) {    if (!(mlH >= 0) || mlH > this.maxRateMlH) throw new Error('rate is outside the pump range');    this.mode = MODES.MANUAL;    this.manualRate = (mlH / 60) * this.concentration;  }   /** Give a bolus (dose units) at the pump's maximum rate. Manual mode only. */  bolus(dose) {    if (this.mode === MODES.PLASMA || this.mode === MODES.EFFECT) {      throw new Error('bolus is not available during TCI; raise the target instead');    }    if (!(dose > 0)) throw new Error('bolus dose must be positive');    if (this.mode === MODES.OFF) this.mode = MODES.MANUAL;    this.bolusRemaining += dose;  }   pause() {    this.paused = true;  }  resume() {    this.paused = false;    this.untilControl = 0;  }  stop() {    this.mode = MODES.OFF;    this.target = 0;    this.manualRate = 0;    this.bolusRemaining = 0;  }   /** Advance the pump by whole seconds of simulated time. */  tick(seconds = 1) {    for (let i = 0; i < seconds; i++) {      let rate = 0;      if (!this.paused) {        if (this.mode === MODES.PLASMA || this.mode === MODES.EFFECT) {          if (this.untilControl <= 0) {            this.controlRate =              this.mode === MODES.PLASMA ? this.#plasmaRate() : this.#effectRate();            this.untilControl = CONTROL_INTERVAL_S;          }          this.untilControl--;          rate = this.controlRate;        } else if (this.mode === MODES.MANUAL) {          if (this.bolusRemaining > 0) {            rate = Math.min(this.maxRate, this.bolusRemaining * 60);            this.bolusRemaining = Math.max(0, this.bolusRemaining - rate / 60);          } else {            rate = this.manualRate;          }        }      }      this.state = advance(this.second, this.state, rate);      this.deliveredRate = rate;      this.totalDose += rate / 60;      this.timeS++;    }  }   // Rate that brings the plasma concentration to target at the end of the interval.  #plasmaRate() {    const coasting = advance(this.interval, this.state, 0)[0];    const rate = (this.target * this.model.v1 - coasting) / this.interval.B[0];    return Math.min(this.maxRate, Math.max(0, rate));  }   // Shafer and Gregg's method: the largest rate for this interval whose  // effect-site peak, with nothing given afterwards, does not exceed target.  #effectRate() {    const coasting = [];    let s = advance(this.interval, this.state, 0);    for (let k = 0; k < EFFECT_HORIZON_STEPS; k++) {      coasting.push(s[3]);      s = advance(this.interval, s, 0);    }    const peak = (rate) => {      let max = -Infinity;      for (let k = 0; k < EFFECT_HORIZON_STEPS; k++) {        const v = coasting[k] + rate * this.unitEffect[k];        if (v > max) max = v;      }      return max;    };    if (peak(0) >= this.target) return 0;    if (peak(this.maxRate) <= this.target) return this.maxRate;    let lo = 0;    let hi = this.maxRate;    for (let i = 0; i < 50; i++) {      const mid = (lo + hi) / 2;      if (peak(mid) > this.target) hi = mid;      else lo = mid;    }    return lo;  }   /**   * Seconds until the concentration falls to `level` if the infusion stopped   * now (the pump's "decrement time"). Uses the effect site when the model has   * one, otherwise plasma. Returns 0 if already below, Infinity if over 24 hours.   */  decrementTime(level) {    const index = this.model.ke0 == null ? 0 : 3;    const scale = index === 0 ? 1 / this.model.v1 : 1;    let s = this.state;    if (s[index] * scale <= level) return 0;    for (let t = CONTROL_INTERVAL_S; t <= 24 * 3600; t += CONTROL_INTERVAL_S) {      s = advance(this.interval, s, 0);      // During the first minutes the effect site may still be rising.      if (s[index] * scale <= level) return t;    }    return Infinity;  }   /** Display values for the pump screen. */  snapshot() {    return {      timeS: this.timeS,      mode: this.mode,      paused: this.paused,      target: this.target,      cp: this.cp,      ce: this.ce,      rate: this.deliveredRate,      rateMlH: this.rateMlH,      volumeMl: this.volumeMl,      totalDose: this.totalDose,    };  }}

// Three-compartment model with an effect site.// FOR EDUCATION ONLY. NOT FOR CLINICAL USE.//// State is [a1, a2, a3, ce]: drug amounts in the three compartments (dose// units) and the effect-site concentration. Infusion rates are dose units per// minute. Plasma concentration is a1 / v1. function derivative(m, s, rate) {  const ke0 = m.ke0 ?? 0;  return [    rate - (m.k10 + m.k12 + m.k13) * s[0] + m.k21 * s[1] + m.k31 * s[2],    m.k12 * s[0] - m.k21 * s[1],    m.k13 * s[0] - m.k31 * s[2],    ke0 * (s[0] / m.v1 - s[3]),  ];} function rk4(m, s, rate, h) {  const add = (a, b, f) => a.map((x, i) => x + f * b[i]);  const k1 = derivative(m, s, rate);  const k2 = derivative(m, add(s, k1, h / 2), rate);  const k3 = derivative(m, add(s, k2, h / 2), rate);  const k4 = derivative(m, add(s, k3, h), rate);  return s.map((x, i) => x + (h / 6) * (k1[i] + 2 * k2[i] + 2 * k3[i] + k4[i]));} /** * Precomputes the exact-enough linear step for a fixed time step, so that * advancing the model is a small matrix multiplication: *   next = A * state + B * rate      (rate constant during the step) */export function buildStepper(model, dtSeconds) {  const sub = Math.max(10, Math.ceil(dtSeconds * 10));  const h = dtSeconds / 60 / sub;  const run = (start, rate) => {    let s = start;    for (let i = 0; i < sub; i++) s = rk4(model, s, rate, h);    return s;  };  const columns = [0, 1, 2, 3].map((i) => run([0, 0, 0, 0].map((_, j) => (i === j ? 1 : 0)), 0));  const A = [0, 1, 2, 3].map((row) => columns.map((col) => col[row]));  const B = run([0, 0, 0, 0], 1);  return { A, B, dtSeconds };} /** Advances a state by one stepper interval at a constant infusion rate. */export function advance(stepper, state, rate) {  const { A, B } = stepper;  const out = [0, 0, 0, 0];  for (let i = 0; i < 4; i++) {    out[i] =      A[i][0] * state[0] + A[i][1] * state[1] + A[i][2] * state[2] + A[i][3] * state[3] + B[i] * rate;  }  return out;} export const emptyState = () => [0, 0, 0, 0]; /** Minutes from an IV bolus to the peak effect-site concentration. */export function timeToPeakEffect(model) {  if (model.ke0 == null) return null;  const stepper = buildStepper(model, 1);  let s = [1, 0, 0, 0];  let peak = 0;  let peakAt = 0;  for (let t = 1; t <= 4 * 3600; t++) {    s = advance(stepper, s, 0);    if (s[3] > peak) {      peak = s[3];      peakAt = t;    } else if (t > peakAt + 60) break;  }  return peakAt / 60;} /** The ke0 (per minute) that gives the requested time to peak effect (minutes). */export function ke0FromTimeToPeak(model, tPeakMinutes) {  let lo = 0.005;  let hi = 10;  for (let i = 0; i < 40; i++) {    const mid = Math.sqrt(lo * hi);    // A larger ke0 gives an earlier peak.    if (timeToPeakEffect({ ...model, ke0: mid }) > tPeakMinutes) lo = mid;    else hi = mid;  }  return Math.sqrt(lo * hi);}

1 : Math.min(1, (this.simTime - o.start) / o.duration);      out[key] = o.from + (o.to - o.from) * done;    }    if (out.dia > out.sys - 5) out.dia = Math.max(0, out.sys - 5);    if (out.re < out.se) out.re = out.se;    return out;  }   /** Everything the screens need. 'none',        stimNow: Number((pt.stimLevel + pt.stimPulse).toFixed(1)),        ventilated: pt.ventilated,        bleeding: pt.bleeding,        bloodLoss: Math.round(pt.deficit * 100),        lineConnected: this.lineConnected,        log: this.log.slice(-80),      },    };  }   logCsv() {    return ['time,event', ...this.log.map((e) => `${e.time},"${e.text.replaceAll('"', '""')}"`)].join('\n');  }   /** Apply one action from a screen. Throws an Error with a readable message if it is not valid. */  action(a) {    const pump = () => {      const p = this.pumps.find((x) => x.id === a.pump);      if (!p) throw new Error('No such pump');      return p;    };    const pt = this.patient;    switch (a.type) {      // ----- pump screens -----      case 'pumpKey':        pump().unit.key(String(a.key));        break;      case 'pumpSelect':        pump().unit.select(Number(a.index));        break;      case 'pumpPower': {        const p = pump();        if (p.unit.on) {          if (p.unit.infusion) this.note(`Pump ${p.id}: Pump switched off`);          p.unit.powerOff();        } else p.unit.powerOn();        break;      }      case 'addPump':        this.addPump();        break;      case 'removePump': {        const p = pump();        if (p.unit.infusion) this.note(`Pump ${p.id}: removed while infusing`);        this.pumps = this.pumps.filter((x) => x !== p);        break;      }      case 'setStyle':        if (!STYLES[a.style]) throw new Error('Unknown pump style');        this.styleId = a.style;        for (const p of this.pumps) p.unit.setStyle(a.style);        break;       // ----- monitor -----      case 'setModules':        if (a.from === 'monitor' && this.monitorLocked) throw new Error('The monitor is locked by the instructor');        if (!Array.isArray(a.modules)) throw new Error('modules must be a list');        this.modules = a.modules.map(String).slice(0, 20);        break;      case 'override': {        if (a.from === 'monitor' && this.monitorLocked) throw new Error('The monitor is locked by the instructor');        if (!(a.key in pt.v) || !Number.isFinite(a.value)) throw new Error('Unknown vital sign or value');        const seconds = Math.max(0, Number(a.seconds) || 0);        this.overrides[a.key] = { from: this.vitals()[a.key], to: a.value, start: this.simTime, duration: seconds };        this.note(`${a.from === 'monitor' ? 'Monitor screen' : 'Instructor'} set ${a.key} to ${a.value}${seconds ? ` over ${seconds} s` : ''}`);        break;      }      case 'release':        if (a.key) delete this.overrides[a.key];        else this.overrides = {};        this.note(`Instructor returned ${a.key ?? 'all values'} to automatic`);        break;       // ----- instructor: time and case -----      case 'setSpeed':        if (!SPEEDS.includes(a.speed)) throw new Error('Unknown speed');        this.speed = a.speed;        break;      case 'setPaused':        this.paused = !!a.paused;        this.note(this.paused ? 'Simulation paused' : 'Simulation resumed');        break;      case 'reset':        if (!PRESETS[a.preset]) throw new Error('Unknown patient');        this.reset(a.preset);        break;      case 'lockMonitor':        this.monitorLocked = !!a.on;        break;      case 'trendShow':        if (!(a.line in this.trendShow)) throw new Error('Unknown graph line');        this.trendShow[a.line] = !!a.on;        break;      case 'showTrend':        this.showTrend = !!a.on;        break;       // ----- instructor: events -----      case 'event':        this.#event(a);        break;      default:        throw new Error(`Unknown action: ${a.type}`);    }  }   #event(a) {    const pt = this.patient;    switch (a.name) {      case 'intubation':        pt.stimPulse = Math.max(pt.stimPulse, 8);        this.note('Event: laryngoscopy and intubation');        break;      case 'incision':        pt.stimPulse = Math.max(pt.stimPulse, 6);        if (pt.stimLevel < STIM_LEVELS.moderate) pt.stimLevel = STIM_LEVELS.moderate;        this.note('Event: skin incision (surgery ongoing)');        break;      case 'stim':        if (!(a.level in STIM_LEVELS)) throw new Error('Unknown stimulation level');        pt.stimLevel = STIM_LEVELS[a.level];        this.note(`Surgical stimulation: ${a.level}`);        break;      case 'ventilation':        pt.ventilated = !!a.on;        this.note(pt.ventilated ? 'Ventilation started' : 'Ventilation stopped (spontaneous breathing)');        break;      case 'bleeding':        pt.bleeding = !!a.on;        this.note(pt.bleeding ? 'Event: bleeding started' : 'Bleeding controlled');        break;      case 'fluid':        pt.deficit = Math.max(0, pt.deficit - 0.2);        this.note('Fluid bolus given');        break;      case 'pressor':        pt.pressor = Math.min(1.5, pt.pressor + 1);        this.note('Vasopressor given');        break;      case 'anticholinergic':        pt.chrono = Math.min(1.5, pt.chrono + 1);        this.note('Anticholinergic given');        break;      case 'line':        this.lineConnected = !!a.connected;        this.note(this.lineConnected ? 'IV line reconnected' : 'Event: IV line disconnected (pumps run, no drug reaches patient)');        break;      case 'occlusion': {        const p = this.pumps.find((x) => x.id === a.pump);        if (!p) throw new Error('No such pump');        p.unit.setOcclusion(!!a.on);        this.note(`Pump ${p.id}: ${a.on ? 'Event: line occluded' : 'occlusion cleared'}`);        break;      }      default:        throw new Error(`Unknown event: ${a.name}`);    }  }}

// Monitor sounds: pulse beep (pitch follows SpO2) and alarm tones.// Browsers only allow sound after the user has pressed something, so sound// starts switched off and is turned on with the Sound button. export class MonitorAudio {  constructor() {    this.ctx = null;    this.enabled = false;  }   enable() {    this.ctx ??= new (window.AudioContext || window.webkitAudioContext)();    this.ctx.resume();    this.enabled = true;  }   disable() {    this.enabled = false;  }   #tone(freq, delay, duration, volume, type = 'sine') {    const ctx = this.ctx;    const start = ctx.currentTime + delay;    const osc = ctx.createOscillator();    const gain = ctx.createGain();    osc.type = type;    osc.frequency.value = freq;    gain.gain.setValueAtTime(0, start);    gain.gain.linearRampToValueAtTime(volume, start + 0.008);    gain.gain.setValueAtTime(volume, start + duration - 0.015);    gain.gain.linearRampToValueAtTime(0, start + duration);    osc.connect(gain).connect(ctx.destination);    osc.start(start);    osc.stop(start + duration + 0.02);  }   /** One pulse beep. 100% is high-pitched; the pitch drops as SpO2 falls. */  pulse(spo2) {    if (!this.enabled) return;    const freq = 880 * 2 ** ((Math.max(60, spo2) - 100) / 20);    this.#tone(freq, 0, 0.07, 0.12);  }   /** One alarm burst: 'high' is five fast beeps, 'medium' is three slower ones. */  alarm(priority) {    if (!this.enabled) return;    if (priority === 'high') {      for (const d of [0, 0.15, 0.3, 0.6, 0.75]) this.#tone(988, d, 0.1, 0.2, 'triangle');    } else {      for (const d of [0, 0.28, 0.56]) this.#tone(660, d, 0.18, 0.16, 'triangle');    }  }}

// Waveform generators (ECG, pleth, arterial, CVP, CO2, EEG) and the sweeping// trace that draws them.
